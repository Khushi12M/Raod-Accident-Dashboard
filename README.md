# Road Accident Dashboard

## Project Overview

This project presents an interactive Road Accident Dashboard created to analyze road accident data and identify important patterns and trends.

The dashboard provides a clear view of accident-related KPIs and visual insights to support better understanding of road accident patterns.

## Tools Used

* Microsoft Excel
* Pivot Tables
* Charts and Visualizations
* Data Cleaning and Analysis

## Key KPIs

* Total Number of Accidents
* Total Casualties
* Fatal Casualties
* Serious Casualties
* Slight Casualties

## Dashboard Features

* KPI cards for important accident metrics
* Accident trend analysis
* Casualty analysis
* Interactive visualizations
* Easy-to-understand dashboard layout
